# ULTRASONICA

### Engineering Experience. Modern Software. Practical AI.

**ULTRASONICA** is a corporate website project representing a technology and engineering-oriented business focused on software development, digital solutions, and the practical application of artificial intelligence.

The project reflects an approach built around combining engineering knowledge, software development experience, and modern technologies to solve real-world business and technical challenges.

---

## About the Project

The ULTRASONICA website is designed to present the company's background, capabilities, services, and approach to technology.

Its visual identity and structure aim to communicate:

- Engineering expertise and technical reliability.
- Modern frontend and software development.
- Practical AI research, evaluation, and implementation.
- A focus on real business needs rather than technology trends alone.
- A combination of analytical thinking and hands-on implementation.

The website is being developed as a modern, responsive web application.

## Technology Stack

The project uses the following technologies:

- **React** – component-based user interface development.
- **TypeScript** – static typing and improved code maintainability.
- **Vite** – frontend development environment and build tooling.
- **Tailwind CSS** – utility-first styling.
- **React Context** – application-level language state management.

## Project Structure

The application follows a component-based architecture, separating page composition, layout elements, reusable UI components, and individual content sections.

```text
src/
├── components/
│   ├── layout/
│   ├── sections/
│   │   └── home/
│   └── ui/
├── context/
├── i18n/
└── pages/
```

The structure is intended to support:

- Reusable components.
- Separation of responsibilities.
- Consistent visual design.
- Maintainable application code.
- Further development and integration of new features.

## Getting Started

### Requirements

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/IT2021db/ULTRASONICA.git
```

Navigate to the project directory:

```bash
cd ULTRASONICA
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local development address in the terminal.
